# 08_Automation — 自动化

> 把稳定流程沉淀为自动化工作流，由 CEO_Agent 编排。对应 8 大目标中的“自动化”。

## 子目录

| 目录           | 用途                                    |
| -------------- | --------------------------------------- |
| `n8n/`         | n8n 工作流实现（JSON）                  |
| `MCP/`         | MCP 服务/工具配置                       |
| `API/`         | 第三方 API 对接说明                     |
| `Cron/`        | 定时任务配置                            |
| `Workflows/`   | 工作流设计稿与 ETL 脚本                 |

## 上线原则
1. 先在 `Workflows/` 出设计稿（节点图 + 数据流 + 异常处理）
2. dry-run 通过后再上线
3. 凭证走环境变量，不写入仓库
4. 上线后在 `CHANGELOG.md` 记录
