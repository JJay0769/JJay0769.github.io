# KPI — KPI 字段口径定义

> 所有 KPI 的权威口径定义，看板与报告必须一致。

## 指标定义

| 指标 | 全称 | 定义 | 计算公式 |
| ---- | ---- | ---- | -------- |
| GMV | Gross Merchandise Volume | 成交总额 | Σ订单金额 |
| ROAS | Return on Ad Spend | 广告回报 | 广告带来收入 / 广告花费 |
| CPA | Cost Per Action | 单次获客成本 | 广告花费 / 转化数 |
| CVR | Conversion Rate | 转化率 | 转化数 / 访客数 |
| CTR | Click-Through Rate | 点击率 | 点击数 / 曝光数 |
| AOV | Average Order Value | 客单价 | GMV / 订单数 |
| CAC | Customer Acquisition Cost | 客户获取成本 | 总获客花费 / 新客数 |
| LTV | Lifetime Value | 客户终身价值 | 客单价 × 复购次数 × 毛利率 |

## 归因模型
- 默认：末触归因
- 实验时可选：首触 / 数据驱动
- 报告必须标注使用的归因模型

## 时间口径
- 日：自然日（Asia/Shanghai）
- 周：周一至周日
- 时区统一 Asia/Shanghai
