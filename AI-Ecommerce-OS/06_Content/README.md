# 06_Content — 内容素材库

> Content_Agent 产出的全部内容素材归集于此。

## 子目录

| 目录       | 用途                         |
| ---------- | ---------------------------- |
| `Images/`  | 图片创意 brief 与 AI 稿      |
| `Videos/`  | 视频脚本与分镜               |
| `Scripts/` | 长文案（详情页/邮件/贴文）   |
| `Hooks/`   | Hook 文案库                  |
| `CTA/`     | CTA 文案库                   |
| `UGC/`     | UGC 与达人脚本               |

## 命名规范

`YYYYMMDD_产品简称_类型_vX.{md,json}`

例：`20260801_pet-remover_hooks_v1.md`

## 关联

每条内容在文件头部标注 `product_id` 与卖点，便于 Marketing_Agent 数据回流。
