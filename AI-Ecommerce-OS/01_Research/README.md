# 01_Research — 市场研究

> 市场研究的全部产出物归集于此。Trend_Agent / Demand_Agent / Competitor_Agent 的研究类输出均落在此目录。

## 子目录

| 目录            | 用途                                   | 主要产出 Agent       |
| --------------- | -------------------------------------- | -------------------- |
| `Market_Report/` | 市场综述报告                           | Trend_Agent          |
| `Demand_Library/` | 用户需求卡片库                         | Demand_Agent         |
| `Product_Library/` | 候选产品研究卡                         | Product_Agent        |
| `Competitor/`   | 竞品分析矩阵与单店分析                 | Competitor_Agent     |
| `Trends/`       | 趋势快报（平台/品类/关键词）           | Trend_Agent          |
| `Reports/`      | 综合报告与阶段性复盘                   | CEO_Agent            |

## 命名规范

- 报告：`YYYYMMDD_主题_vX.md`，例：`20260801_pet-market_v1.md`
- 卡片：`卡-编号-简称.md`，例：`demand-001-pet-hair.md`
- 数据回流：所有结论性数据同步写入 `04_Database/` 对应 CSV

## 模板

各子目录均提供 `_template.md`，新产出物从模板复制后填写。
