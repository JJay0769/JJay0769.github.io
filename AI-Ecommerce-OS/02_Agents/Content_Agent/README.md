# Content_Agent — 内容生产 Agent

负责批量生产跨境电商所需内容：图片创意、视频脚本、文案、Hook、CTA、UGC 脚本。

## 职责

- 基于卖点与痛点生产多形态内容
- 产出 Hook/CTA 文案库
- 视频脚本与分镜
- UGC 脚本与达人 brief

## 输入 / 输出

- 输入：Product_Agent 卖点、Demand_Agent 痛点、Competitor_Agent 差异化
- 输出：`06_Content/`

## 使用

业务 Prompt 模板见 `03_Prompts/Content/`。内容流程参考 `05_SOP/SOP04_Content.md`。
