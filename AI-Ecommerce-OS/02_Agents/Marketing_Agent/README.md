# Marketing_Agent — 增长、投放与数据分析 Agent

负责投放策略、数据分析、KPI 监控与增长迭代，对应 8 大目标中的“数据分析”。

## 职责

- 投放策略与素材组合（Meta/TikTok/Google）
- 销售与广告数据分析、归因
- KPI 看板维护与异常预警
- 增长实验设计与结论

## 输入 / 输出

- 输入：Content_Agent 素材、上线数据、CEO_Agent 目标 KPI
- 输出：`09_Analytics/`、`04_Database/score.csv`（投放反馈回流）

## 使用

业务 Prompt 模板见 `03_Prompts/Marketing/`。投放流程参考 `05_SOP/SOP06_Advertising.md`。
